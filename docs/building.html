Build from source

The agent is plain C++17 with OpenSSL, libcurl, libxml2, bzip2 and zlib. RHEL 9 and 10 builds use the system OpenSSL, 3.5 or later. RHEL 8 has two packages: one on RHEL 8's own OpenSSL 1.1.1 and one with OpenSSL 3.5 and libcurl built in (see Install).

What you need

# dnf install gcc-c++ make openssl-devel libcurl-devel libxml2-devel bzip2-devel zlib-devel

On RHEL 8 a plain make builds on OpenSSL 1.1.1 (make DEFINES=-DDRRA_FIPS_BUILD is what the linux_reporting_agent package uses). For the openssl35 build, build the RPMs (below), or see the %build section of the spec file for DEFINES, SSL_CFLAGS, SSL_LIBS, CURL_CFLAGS and CURL_LIBS.

Build with make

$ wget https://datareel.com/downloads/linux_reporting_agent/linux_reporting_agent-1.1.3.tar.gz
$ tar xzf linux_reporting_agent-1.1.3.tar.gz && cd linux_reporting_agent-1.1.3
$ make
# make install            # /usr/sbin/drra, /etc/drra, the systemd unit
# systemctl daemon-reload

make check-openssl fails unless drra and every library it loads use OpenSSL 3.5 or later (tools/check_openssl.sh --fips checks the RHEL 8 linux_reporting_agent build for RHEL 8's OpenSSL 1.1.1), and runs drra selftest. drra selftest https://your.server/ also prints the TLS version, cipher and key exchange group of a connection.

make install takes DESTDIR, PREFIX, SYSCONFDIR and UNITDIR. It overwrites /etc/drra/drra.ini: keep a copy of yours.

Build the RPMs

$ tools/build_rpms.sh

Builds the source tarball and the RHEL 8, 9 and 10 RPMs in UBI containers with podman, into output/, with a .sha256sum file. The spec file is rpm/linux_reporting_agent.spec. On RHEL 8 it builds two packages: linux_reporting_agent on the system libraries, and linux_reporting_agent-openssl35 (rpmbuild --define "openssl35 1") with OpenSSL and libcurl built from their release tarballs, which it downloads once and checks against tools/bundled.sha256. Every RPM build runs tools/check_openssl.sh on each binary and fails if one has the wrong OpenSSL.

Tests

$ tests/drsm_test.sh           # DRSM plugins and pages against a DRSM checkout
$ tests/uploads_test.sh        # hook uploads end to end with php -S
$ tests/rpm_install_test.sh <el8 rpm> <el8 openssl35 rpm> [<old>.el8.x86_64.rpm]
                             # RHEL 8 packages: FIPS mode, upgrade, switch, removal

tools/build_rpms.sh also scans every RPM and tarball it makes against a release blocklist kept outside the repository (DRRA_RELEASE_BLOCKLIST, default ~/.config/drra_release/blocklist.txt: host names and domains that must never be published) and fails on a match or a missing list.
