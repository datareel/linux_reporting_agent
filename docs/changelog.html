What's new

Release 1.1.2 fixes the advisory severity of RHEL 10 scans. Release 1.1.1 lets a scan run by hand update the dashboard. Release 1.1 is the first stable release of the DataReel Reporting Agent for Linux. It has everything from the two 1.0 betas: release 1.0 beta 2 added report hooks and hook uploads, and release 1.0 beta 1 was the first release.

Release 1.1.2 November 2026

  • Advisory severity on RHEL 10: CSAF/VEX scans use Red Hat's own severity for each advisory, from dnf, instead of the worst severity of its CVEs. A kernel update Red Hat rates Important was counted as Critical.

Release 1.1.1 November 2026

  • Scans by hand: drra scan sends a report with the results right away, and with [scan] enabled=0 (the default) every report carries the last manual scan (mode=manual) instead of saying the scan is off.

Release 1.1 October 2026

  • Stable release of the 1.0 betas, with RPMs for RHEL 8, 9 and 10 (linux_reporting_agent-1.1-1.el<N>.x86_64.rpm).
  • Documentation set: these pages, also in docs/ of the source code, made by tools/gen_docs.py.
  • install_server.sh makes the hook uploads folder, lets the DRSM user read it, and blocks hook_lib.php from the web.

Release 1.0 beta 2 October 2026

  • Report hooks: site checks in /etc/drra/report.d run with every report, in a HOOKS section DRSM shows as checks (LRA_HOOK=, linux/hooks). drra hooks runs them now. See Hooks.
  • Hook uploads: send reports from other sources, such as a scan run by hand or a backup job's result, with drra submit --hook <id> [--now] <file> or the spool folders. The server's new hook.php checks the signature and a manifest per hook.
  • New [hooks] and [uploads] settings, [https] hook_path, the UPLOADS report section and the drra-upload group.

Release 1.0 beta 1 October 2026

  • Agent: C++ systemd service for RHEL 8, 9 and 10, reporting every 15 minutes: system, usage, security settings, failed services, updates and installed packages.
  • Signed uploads: the Windows agent's protocol: certificate registration, approval on an admin page or with an enrollment token, and signed, time stamped, one time uploads over HTTPS. CIFS and SCP delivery too.
  • Vulnerability scans: OpenSCAP OVAL on RHEL 8 and 9, Red Hat CSAF/VEX on RHEL 10 (server index built by vex_sync.php, with unfixed CVE counts), dnf updateinfo as fallback, optional SCAP compliance profiles. Off by default.
  • DRSM: the lra collector, linux/* plugins and the Vulnerabilities page.
  • Packages: RPMs for RHEL 8, 9 and 10 with a hardened systemd unit.
