Configuration

Every setting is in /etc/drra/drra.ini. The agent reads it again before every report, so changes need no restart; systemctl reload drra starts the next report now.

The settings file

A setting left out uses its default. drra config prints the settings in use. The file is root only (mode 0600) because it can hold the enrollment token.

[delivery]

SettingDefaultWhat it does
methodshttpsOne or more of https, cifs, scp, separated by commas. Every listed method runs each cycle.

[https]

SettingDefaultWhat it does
hostreports.example.comReport server
port443443 for HTTPS, 80 for HTTP
upload_path/linux/upload/upload.phpUpload page
register_path/linux/upload/register.phpRegistration page
hook_pathemptyHook upload page; empty uses hook.php next to upload_path
enrollment_tokenemptyThe enrollment_token from server.ini; empty to have an admin approve the host
use_https10 = plain HTTP, only for a test server
verify_peer1Check the server certificate and host name. 0 only for a test server; use ca_file for a private CA.
ca_fileemptyCA bundle (PEM) for a private CA; empty uses the system trust store
timeout_seconds60Seconds before an upload is given up

[cifs]

Copies the report to a Windows (SMB/CIFS) file share with smbclient (package samba-client).

SettingDefaultWhat it does
shareemptyShare, for example //fileserver/reports
directoryemptyFolder inside the share
credentials_file/etc/drra/cifs_credentialsShare login in smbclient -A format (username =, password =, domain =), mode 0600; empty for a guest share
smbclient_path/usr/bin/smbclient
timeout_seconds120

[scp]

SettingDefaultWhat it does
host, port, userempty, 22, emptySSH server and account that receive the report
key_file/etc/drra/id_ed25519Private key with no passphrase, mode 0600
remote_diremptyFolder on the server, for example the report server's reports_dir
known_hosts_file/var/lib/drra/known_hostsHost key of the server
strict_host_key_checkingyesyes (only a key already in known_hosts) or accept-new (save it on the first connection)
scp_path/usr/bin/scp
timeout_seconds120Seconds before a hung transfer is stopped

[agent]

SettingDefaultWhat it does
report_interval_minutes15Minutes between reports. 15 matches the DRSM check interval.
cpu_sample_seconds5Seconds the CPU use is sampled for
report_dir/var/lib/drraWhere the report is written before it is sent
log_file/var/log/drra/drra.logLog of every report and upload
data_dir/var/lib/drraAgent key, certificate, registration and scan results
check_updates1List pending package updates (from the dnf metadata cache)
updates_refresh_hours24Hours between dnf makecache runs; 0 leaves it to dnf-makecache.timer
command_timeout_seconds300Seconds before a command the agent runs (rpm, dnf, systemctl) is stopped

[scan]

See Vulnerability scans for how the sources work.

SettingDefaultWhat it does
enabled01 turns the vulnerability scan on
interval_hours24Hours between scans
sourceautoauto, oval, csaf or dnf
oval_feed_urlemptyOVAL feed (https URL or local file, .xml or .xml.bz2); empty picks Red Hat's feed for the release
csaf_index_urlemptyCSAF/VEX index (https URL or local file, {major} is replaced with the release); empty uses vex_index.php next to upload_path
unfixed_list_severityImportantCVEs with no fix yet are counted, and listed at or above this severity (Critical, Important, Moderate, Low or none)
oscap_path/usr/bin/oscap
upload_html1Send the OpenSCAP HTML reports to the server
compliance_profileemptySCAP Security Guide profile for a compliance scan, for example cis_server_l1 or stig; empty = none
compliance_datastreamemptySCAP data stream; empty picks ssg-rhel<release>-ds.xml
timeout_minutes60Minutes before a scan is stopped
